# Metisor Game Engine

> A complete game engine built for creating immersive worlds, interactive experiences, and modern games.

---

## Overview

Metisor is a next-generation game engine designed to give developers the tools needed to create complete games and interactive applications.

Built with a focus on flexibility, extensibility, and modern rendering, Metisor provides a foundation for building everything from small experimental projects to large-scale interactive experiences.

The engine combines a powerful runtime, advanced graphics capabilities, and an extensible architecture to provide developers with full control over their creative workflow.
